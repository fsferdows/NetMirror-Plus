# MovieBox Plus - Official Chrome Extension (Manifest V3)

Stream worldwide movies, TV series, anime, and 24/7 live sports directly from your browser toolbar!

---

## 🚀 How to Install in Google Chrome, Microsoft Edge, Brave, and Opera

You can install this extension directly into any Chromium browser in 3 simple steps:

### Step 1: Open Extension Management
- **Google Chrome**: Go to `chrome://extensions/`
- **Microsoft Edge**: Go to `edge://extensions/`
- **Brave Browser**: Go to `brave://extensions/`
- **Opera**: Go to `opera://extensions/`

### Step 2: Enable "Developer Mode"
- In the top-right corner of the Extensions page, toggle the **Developer mode** switch **ON**.

### Step 3: Load Unpacked
- Click the **"Load unpacked"** button (top-left).
- Select the `extension` folder from this repository (`/Users/user/Desktop/Moviebox/extension`).
- 🎉 **Done!** The MovieBox Plus icon will appear in your browser toolbar!

## ✨ Features

- **Instant 4K Streaming**: Click any movie or TV series card to stream in 4K Ultra HD.
- **Real-Time Search**: Search thousands of movies and series instantly as you type.
- **Omnibox Address Bar Shortcut**:
  - Type `mb` in your Chrome address bar, press `Tab` or `Space`, type any movie or show title (e.g. `mb Loki` or `mb Inception`), and press `Enter` to search and watch!
- **Right-Click Context Menu**:
  - Highlight any movie or show title on any website, right click, and choose **"Search on MovieBox Plus"**.
- **Live Sports Launcher**: Instant one-click access to 24/7 Cricket, Football, Premier League, NBA, and F1 live feeds.
- **Ad-Free & Fast**: Zero popups, zero intrusive ads.
